# demo

Assets for the hackathon demo. **Never use a real inbox or real personal data.**

- `seed-inbox/`: fake signup, welcome, OTP, receipt and reply emails for a fictional user, to load into a fresh demo Gmail account.
  - Target numbers for the wow moment: ~214 companies, 61 dormant 3+ years, 12 high-sensitivity (including 2 banks).
  - Include replies covering each class: 5 confirmed, 1 ID requested, 1 no reply.
- `report-card/`: mock company report card (response rate, median days).

Script: [docs/hackathon/demo-script.md](../docs/hackathon/demo-script.md).
