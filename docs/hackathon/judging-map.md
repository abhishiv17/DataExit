# Judging keywords → features

| Keyword | How we hit it |
| --- | --- |
| **Everyday** | Weekly digest, new-signup detection, rural "Is this a scam?" daily hook |
| **Existing apps** | Gmail, Calendar, WhatsApp, SMS; no new app to install |
| **Beyond basic integrations** | Multi-server orchestration: discovery → legal reasoning (retention overrides) → drafting → deadlines → classification → escalation |
| **Useful** | Turns a new law into one-tap actions; Hindi; restrict-use for banks instead of a dead end |
| **Reliable** | Curated directory, deadline tracking, reply classification, evidence locker, verification |
| **Controlled** | Approval tiers, 10-minute undo window, hash-chained audit log, every suggestion cites its source |
