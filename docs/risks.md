# Risks and mitigations

| Risk | Mitigation |
| --- | --- |
| Erasure rights not enforceable until 13 May 2027 | Label requests as policy-based; pitch "get ready now" |
| Wrong deletion causes harm | Approval tiers, review, 10-minute undo window |
| Regulated companies must retain data | Retention rules in directory; propose restrict use |
| Grievance contacts missing or stale | Curated directory, crowd reports, web lookup, bounce handling |
| Gmail scope verification and trust | Metadata first, on-device SMS, no bodies stored |
| Email-only discovery misses OTP signups | SMS companion, Sign in with Google audit |
| Companies ask for ID | Detect and guide; never auto-share ID |
| Bot impersonated by scammers (rural) | Never ask for OTP/PIN/Aadhaar; say so every time |
| Not a legal service | Lawyer-reviewed templates, disclaimer, user reviews escalations |
| DPDP section numbers wrong | All marked `[verify]` in templates until checked against the gazette |
