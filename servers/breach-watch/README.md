# breach-watch MCP server (future scope)

Alerts the user when a company in their footprint is reported breached.

Planned tool: `check_breaches(companyIds[])` → known incidents, date, data categories exposed, recommended action (change password, withdraw consent, watch for phishing).

Possible sources: CERT-In advisories, company breach notices to the DPB (once Phase III is live from 13 May 2027), public breach databases.

Not part of the hackathon MVP.
